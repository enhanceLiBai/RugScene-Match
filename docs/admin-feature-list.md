# 管理后台功能清单

## 状态说明

- `[x]`：已由用户验收。
- `[ ]`：尚未验收；条目后标注“已开发，待验收”时表示功能已有实现。
- “暂搁置”：保留现有代码，不纳入当前后续开发顺序，用户重新启用后再确认口径和验收。

## 1. 范围与技术路线

- 管理后台采用 React + Ant Design 开发。
- 现有客服匹配页继续保留原生 HTML/JavaScript，不纳入本轮重写。
- 后台通过现有 FastAPI 服务提供数据和操作接口。
- 图片使用缩略图列表、预览和原图下载能力。
- 所有统计均支持按客服和时间范围查看。

## 2. 后台公共能力

- [x] 管理后台登录和管理员身份校验
- [x] 左侧导航：客服数据、买家秀库、客服子账户、异常待处理
- [ ] 顶部账号信息、退出登录
- [ ] 页面加载、空数据、请求失败状态（各功能已局部实现，待统一验收）
- [x] 全局消息提示和删除确认弹窗
- [ ] Ant Design 统一主题、间距、表格和表单样式
