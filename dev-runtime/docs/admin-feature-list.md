# 管理后台功能清单

## 1. 范围与技术路线

- 管理后台采用 React + Ant Design 开发。
- 现有客服匹配页继续保留原生 HTML/JavaScript，不纳入本轮重写。
- 后台通过现有 FastAPI 服务提供数据和操作接口。
- 图片使用缩略图列表、预览和原图下载能力。
- 所有统计均支持按客服和时间范围查看。

## 2. 后台公共能力

- [ ] 管理后台登录和管理员身份校验
- [ ] 左侧导航：客服数据、买家秀库、客服子账户、异常待处理
- [ ] 顶部账号信息、退出登录
- [ ] 页面加载、空数据、请求失败状态
- [ ] 全局消息提示和删除确认弹窗
- [ ] Ant Design 统一主题、间距、表格和表单样式

## 3. 客服数据

### 3.1 数据总览

- [ ] 时间筛选：日、周、月、近 7 天、近 30 天、自定义
- [ ] 匹配成功次数
- [ ] 成交次数
- [ ] 转化率
- [ ] 按日期展示匹配和成交趋势折线图
- [ ] 客服排行表：客服、匹配次数、成交次数、转化率

### 3.2 单个客服详情

- [ ] 选择客服并查看同一时间筛选范围的数据
- [ ] 匹配次数、成交次数、转化率
- [ ] 匹配和成交趋势图
- [ ] 匹配历史记录
- [ ] 匹配记录对应的成交商品
- [ ] 打开记录查看客户图片和当次匹配结果

## 4. 买家秀库

### 4.1 总图库

- [ ] 图片缩略图和 Ant Design 图片预览
- [ ] 商品 ID、商品名称、SKU、上传时间
- [ ] 图片匹配成功次数
- [ ] 商品或 SKU 搜索
- [ ] 时间筛选
- [ ] 分页或加载更多
- [ ] 删除图片
- [ ] 删除前二次确认
- [ ] 图片被历史记录引用时显示关联提示

### 4.2 商品数据

- [ ] 商品搜索和时间筛选
- [ ] 买家秀总数量
- [ ] 总匹配成功次数
- [ ] 总成交次数
- [ ] 总转化率
- [ ] 按匹配成功次数查看图片排序

### 4.3 商品详情筛选

- [ ] 按沙发颜色筛选
- [ ] 按地板颜色筛选
- [ ] 展示各分类图片数量
- [ ] 展示各分类匹配成功次数
- [ ] 展示各分类转化率
- [ ] 分类内按匹配成功次数排序图片

## 5. 客服子账户配置

- [ ] 维持现有客服子账号配置功能
- [ ] 后台继续使用现有账号列表和新增账号能力
- [ ] 本轮不扩展账号状态、密码策略或角色权限

## 6. 异常待处理

- [ ] 客服检索无匹配结果时自动生成异常记录
- [ ] 记录客服、查询时间、客户查询图片和本次查询 ID
- [ ] 记录本次识别出的场景标签及人工确认标签（如有）
- [ ] 记录无结果原因，例如场景筛选后无候选或图库暂无匹配
- [ ] 管理员按时间、客服和处理状态筛选异常
- [ ] 管理员打开异常记录，查看本次完整匹配情况
- [ ] 查看当次查询使用的筛选条件、候选数量和匹配结果快照
- [ ] 支持标记为已查看或已处理

## 7. 预计接口清单

- [ ] `GET /api/admin/statistics`
- [ ] `GET /api/admin/statistics/trend`
- [ ] `GET /api/admin/customers/{id}/statistics`
- [ ] `GET /api/admin/customers/{id}/history`
- [ ] `GET /api/admin/images`
- [ ] `DELETE /api/admin/images/{image_id}`
- [ ] `GET /api/admin/products`
- [ ] `GET /api/admin/products/{product_id}`
- [ ] `GET /api/admin/exceptions`
- [ ] `GET /api/admin/exceptions/{id}`
- [ ] `POST /api/admin/exceptions/{id}/resolve`

## 8. 本轮排除项

- AI 初筛和产品部二筛流程
- 匹配算法和相似度排序重构
- 复杂角色权限体系
- 分布式统计、缓存和高并发专项建设
- 与后台反馈无关的页面重构

## 9. 第一版验收标准

- [ ] 管理员可以进入后台并看到四个功能模块
- [ ] 客服数据可以按时间筛选，并显示总览、趋势和客服排行
- [ ] 可以打开单个客服详情和匹配历史
- [ ] 可以搜索、筛选、预览和删除图库图片
- [ ] 可以查看商品统计，并按沙发颜色、地板颜色筛选
- [ ] 现有客服子账号配置可继续使用
- [ ] 客服检索无结果时会生成异常记录
- [ ] 管理员可以查看异常查询的完整情况并标记已处理
- [ ] 关键操作有加载、空数据、失败和成功提示
