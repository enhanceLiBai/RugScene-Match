## 每日交付流程

1. 完成当天安排的一个需求。
2. 运行该需求的功能测试。
3. 运行直接相关的 Bug 和回归测试。
4. 提供测试结果和访问地址。
5. 用户实际操作验证。
6. 用户确认后勾选对应任务。
7. 开始下一个需求。
